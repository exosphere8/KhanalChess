# KhanalChess

A minimalist chess web app with a bishop as its logo, built as a final-year computer engineering project focused on DevOps and clean code.

Started on November 11, 2026 as a personal challenge: taking an idea from my head to a deployed product, and learning development and operations end to end by building it.

## Stack

- **Backend:** Python, FastAPI, python-chess, PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **DevOps:** Docker, GitHub Actions, Terraform, Kubernetes (planned)

## Status

Early development. The project structure is set up; the game engine comes next.
